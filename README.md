# emkostimarket_dev — сайт-витрина «Емкости Маркет»

README для владельца: как рулить, из чего сделано и почему именно так.

## Что это вообще такое

**Статический сайт.** Все 197 страниц — это готовые HTML-файлы, которые просто лежат и раздаются. Никакого сервера, PHP, базы данных и админки нет и не нужно.

- **Домен:** emkosti.market (оплачивается отдельно у регистратора)
- **Хостинг:** GitHub Pages (бесплатный, у GitHub) — сайт раздаётся с адреса
  `https://boodhis.github.io/emkostimarket_dev/` (пока так, домен подключим после проверки)
- **Репозиторий:** github.com/boodhis/emkostimarket_dev (публичный)

## Как я этим рулю (основной цикл)

```
правка в VS Code → Source Control → Commit → Push → сайт сам обновляется через 1–2 минуты
```

1. Открыть проект: `code ~/emkostimarket` (или иконка в лаунчере)
2. Правишь любой файл (страницу, цену, текст)
3. Слева иконка **Source Control** (git-ветка) → `+` у файла → сообщение → **Commit**
4. Стрелка вниз (**Push**) — или в терминале `git push`
5. GitHub сам: прогоняет тесты → если зелёные, выкладывает на сайт (вкладка **Actions**)

⚠️ Если тесты упали — деплой **не идёт**, сайт остаётся старым. В Actions видно, что сломалось.

**Проверить у себя до пуша:**
```bash
cd ~/emkostimarket && python3 tests/test_site.py    # 29 проверок
```

## Стек — и почему такой

| Слой | Чем сделано | Почему выбрано |
|---|---|---|
| Страницы | Чистый HTML + CSS (+ немного JS) | Быстро, ничего не надо ставить, живёт вечно |
| Генератор | Python-скрипт `src/build.py` | Обычный Python, без фреймворков |
| Картинки | Pillow → WebP (241 → 43 МБ) | Сжатие без потери качества |
| Тесты | `tests/test_site.py` (Python) | Ловит битые ссылки и мусор до публикации |
| Хостинг | GitHub Pages | **Бесплатно** и без обслуживания |
| Контроль версий | Git + GitHub | История всех правок, откат при косяке |

**Ноль лицензий, ноль подписок на софт.** Всё свободное/бесплатное:

- **Python, Pillow** — свободные, ничего не стоят
- **VS Code** — бесплатный
- **GitHub Pages** — бесплатный тариф хватает (лимит 1 ГБ на сайт, у нас ~50 МБ)
- **Git** — бесплатный

Единственная регулярная статья расходов — **домен** (~500–900 ₽/год).

## Почему ушли от WordPress

WordPress стоял на старом сервере (192.168.0.212, nginx + PHP-FPM + MariaDB). Проблемы:

1. **Обслуживание.** WordPress, тема и плагины постоянно обновляются — иначе дыры в безопасности. Это ручная работа + место для поломок. Со статикой обновлять нечего.
2. **База данных + PHP** — два лишних слоя, которые могут упасть (MySQL отвалился → сайт лежит). Статике нечему падать.
3. **Мусор в разметке.** WPBakery генерил кашу из шорткодов `[vc_row...]` — плохо для SEO и скорости. Проверка `test_no_wordpress_leftovers` теперь гарантирует, что такого больше нет.
4. **Тяжесть.** Старый сайт тянул чужие скрипты и стили; новый — 197 страниц, локальные ресурсы, карточки грузятся мгновенно.
5. **Хостинг.** Статику раздаёт GitHub бесплатно; для WP нужен свой сервер с PHP и БД.

**Что потеряли:** админку «покликать мышкой». **Что получили:** правки через код с тестами, нулевое обслуживание, скорость.

## Структура репозитория

```
~/emkostimarket/
├── index.html, about/, contacts/, ...   ← готовый сайт (то, что уходит на хостинг)
├── catalog/        20 категорий
├── product/        166 карточек товаров
├── docs/           документы (оферта, возврат, privacy)
├── delivery/, payment/, about/, contacts/
├── css/, js/, img/  стили, скрипты, картинки (WebP)
├── sitemap.xml, robots.txt, favicon.svg
├── src/            ⚙️ генератор + данные (НЕ уходит на хостинг, но лежит в гите)
│   ├── build.py            пересобирает весь сайт из данных
│   ├── optimize_images.py  жмёт картинки в WebP (нужен доступ к img_raw)
│   └── *.json              выгрузка WooCommerce: товары, категории, страницы
└── tests/test_site.py      29 проверок перед публикацией
```

## Как пересобрать сайт из данных (нужно редко)

Если менялись `src/*.json` (новые товары/цены из старого WordPress):

```bash
cd ~/emkostimarket/src && python3 build.py   # пересоберёт все 197 страниц
```

Скрипт воспроизводит файлы байт-в-байт: перегенерация без правок = ноль изменений в git.

- **Заказы** — принимаем по телефону `+7 (911) 922-57-32` и почте; рабочих форм на сайте нет (пока)
- **Домен** — переключим, когда сайт проверишь

## Правила, которых держимся

- Секреты (пароли, токены) — **только** в волте, в файле «🔐 Доступы и токены.md», никогда в код и README
- На публичный сайт не выносятся IP-адреса, имена хостов, личные данные — тест `test_no_secrets` это ловит
- Внешние ресурсы (чужие шрифты/картинки/скрипты) запрещены — сайт полностью самодостаточный (`test_no_external_resources`)
